State management and components are related, but they solve completely different problems in an app.

1. What is a Component?

A component is a building block of UI.

It is responsible for:

Rendering UI (HTML/JSX)
Handling user interactions
Managing small/local state
Being reusable

Example:

function Button() {
  return <button>Click me</button>;
}

👉 A component = UI + behavior


2. What is State Management?

State management is a system to store and manage data across the whole app.

It is responsible for:

Sharing data between components
Keeping data consistent
Updating UI when data changes
Managing global or server state

Example:

store.user.name
store.cart.items

👉 State management = data brain of the app



===========Prop Drilling=======
What is Prop Drilling?

Prop drilling is when you pass data from a parent component to a deeply nested child component through multiple layers of components that don’t actually need that data.

📦 Simple idea

You pass props like this:

App → Page → Layout → Sidebar → UserProfile

Even though only UserProfile needs the data.

All intermediate components just pass it along.
